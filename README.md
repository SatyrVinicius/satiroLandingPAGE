# Sátiro: Organiza & Cresce

Crie uma landing page moderna, profissional, responsiva (mobile-first) e focada em conversão para a empresa “Sátiro Sistemas”. O público-alvo são pequenas, médias e grandes empresas, porém a linguagem deve ser simples e fácil de entender, voltada principalmente para pequenos empresários e pessoas leigas em tecnologia.

A landing page deve ter como objetivo gerar contatos no WhatsApp, levar pessoas para o Instagram e gerar leads através de um eBook.

As cores predominantes devem ser azul com tons de verde. O design deve ser moderno, limpo, com ícones simples, botões chamativos e foco em conversão. A página deve ser rápida e totalmente responsiva.
